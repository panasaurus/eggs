Eggs

Server definitions for the Panasaurus panel. Every egg runs on images from ghcr.io/panasaurus/images. Import a JSON from the panel (admin area → Nests → import) or download it here and import the file.

    Panasaurus Eggs is MIT licensed and reworks the ptero-eggs game, application and generic collections by the Pterodactyl team, Michael Parker and contributors — author credits are kept inside every egg file.
